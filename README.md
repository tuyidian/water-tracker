# 💧 喝水打卡助手

一个**无需安装、打开就能用**的喝水提醒与打卡网页工具。适合需要提醒自己多喝水的家人朋友。

## ✨ 功能

- 💧 **一键打卡**：小杯 100ml / 中杯 200ml / 大杯 250ml，也支持自定义水量
- ⏰ **定时提醒**：每 30 分钟 ~ 1.5 小时弹窗提醒喝水（仅 7:00–22:00 提醒，达标后自动停止）
- 📊 **统计**：近 7 天达标天数、日均饮水量、连续达标天数
- 📝 **记录**：自动记录每天每次喝水的时间和水量
- 🔒 **隐私安全**：所有数据只保存在您自己的设备上（浏览器本地存储），不上传任何服务器
- 👴 **长辈友好**：大字体、大按钮、中文界面

## 🚀 使用方法

**方式一：在线使用（推荐）**

打开网页即可使用：`https://tuyidian.github.io/water-tracker/`

> 手机浏览器打开后可"添加到主屏幕"，像 App 一样使用。

**方式二：本地使用**

下载本仓库的 `index.html`，用任意浏览器打开即可。

## 💡 使用小贴士

1. 第一次开启"定时提醒"时，浏览器会询问是否允许通知，请选择"允许"
2. 提醒只在早 7 点至晚 10 点之间弹出，不影响休息
3. 换手机/清理浏览器缓存后记录会清空（数据只存在本机）
